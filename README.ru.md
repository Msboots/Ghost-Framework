# Ghost Framework — русский интерфейс

Форк [Midohajhouj/Ghost-Framework](https://github.com/Midohajhouj/Ghost-Framework) с русским меню, подсказками и сообщениями. Нумерация пунктов сохранена.

Журналы сохраняются в `$XDG_STATE_HOME/ghost-framework/logs` или в `~/.local/state/ghost-framework/logs`, если переменная не задана. Для запуска права root не требуются.

## Установка и запуск

Требуются Python 3 с модулем venv, ADB и FFmpeg (включая ffplay для показа экрана).
Для управления телефоном с ПК также требуется установленный [scrcpy](https://github.com/Genymobile/scrcpy).

```bash
git clone https://github.com/Msboots/Ghost-Framework.git
cd Ghost-Framework
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python ghost.py
```

Для подключения по Wi-Fi включите беспроводную отладку на своём Android-устройстве. При необходимости выполните сопряжение через `adb pair`, затем подключитесь командой `adb connect IP:ПОРТ`. Адрес и порт указаны в настройках беспроводной отладки; порт может меняться.

При использовании отдельного сервера ADB задайте его порт:

```bash
ANDROID_ADB_SERVER_PORT=5039 .venv/bin/python ghost.py
```

## Управление телефоном с ПК

1. Подключите свой телефон через ADB. Пункт **2** принимает IPv4-адрес или `IPv4:порт` беспроводной отладки.
2. Выберите **29 — Управлять телефоном с ПК**. Перед подключением выберите разрешение трансляции и максимальную частоту кадров. Доступны исходный размер, ограничение максимальной стороны до 1920, 1280 или 960 пикселей и свой размер (256–8192). Пропорции сохраняются; разрешение дисплея телефона не меняется. Частота кадров задаётся числом от 1 до 240, значение 0 снимает ограничение. Это верхний предел: фактическая частота зависит от телефона, содержимого экрана и сети. Enter выбирает 1280 пикселей и 30 кадр/с. Пункт 0 в выборе разрешения отменяет запуск.
   Если телефонов несколько, выберите нужный из списка. Если подключений нет, Ghost предложит ввести адрес.
3. В окне scrcpy используйте мышь для нажатий и перетаскиваний, клавиатуру — для ввода. Закройте окно для возврата в меню Ghost.

После выбора разрешения и частоты кадров выберите источник: **1 — аудио телефона** (Enter, по умолчанию), **2 — микрофон телефона**, **3 — без звука**. В режиме 1 звук приложений передаётся на компьютер, воспроизведение на самом телефоне отключается на время сеанса. В режиме 2 на ПК передаётся звук с микрофона телефона вместо аудио приложений; захват прекращается при закрытии окна scrcpy. Передача звука требует Android 11 или новее; на Android 11 телефон должен быть разблокирован при запуске. Если захват звука недоступен, scrcpy может продолжить работу только с видео; причина выводится в терминале.

Используется кодек AAC для совместимости с Samsung на LineageOS, где кодировщик Opus может отсутствовать. [Документация scrcpy по звуку](https://github.com/Genymobile/scrcpy/blob/master/doc/audio.md).

Root не требуется. Настройки отдельного сервера ADB наследуются при запуске scrcpy. Первичное сопряжение нового устройства выполняется через `adb pair`.

## Подключение по SSH

Пункт **30 — Подключиться по SSH** открывает терминал телефона. На ПК требуется клиент OpenSSH, на телефоне — запущенный SSH-сервер. Для Termux запустите `sshd`, узнайте имя пользователя командой `whoami`; стандартный порт Termux — 8022. Пароль для входа задаётся командой `passwd` на телефоне, либо заранее настраивается авторизация по публичному ключу.

Введите адрес или имя хоста, имя пользователя, порт и при необходимости путь к приватному SSH-ключу на ПК. Пустой путь использует стандартные ключи, ssh-agent или пароль. При первом подключении OpenSSH запросит проверку ключа сервера. Ghost не сохраняет пароли и не отключает проверку ключей сервера. Команда `exit` возвращает в меню Ghost; пустой адрес отменяет подключение.

SSH открывает командную оболочку. Для управления экраном используется пункт 29 через ADB.

## Управление экраном через SSH-туннель

Пункт **31 — Управлять экраном через SSH-туннель** передаёт подключение ADB и потоки scrcpy через SSH. Выберите разрешение, FPS и источник звука, затем введите параметры SSH и порт ADB на телефоне. Вводится именно порт подключения ADB (беспроводной отладки или уже работающего TCP ADB), а не порт сопряжения и не порт SSH. Адрес ADB со стороны SSH-сервера — `127.0.0.1`: SSH-сервер должен работать на самом телефоне.

SSH-туннель не включает отладку Android: она должна работать заранее, а компьютер должен быть авторизован в ADB. Если нужно, выполните первоначальное сопряжение через `adb pair`. SSH сам по себе не предоставляет разрешение ADB. Для входа по паролю используйте обычный интерактивный терминал; Ghost ожидает авторизацию до 60 секунд.

Локальный порт выбирается автоматически и слушает только `127.0.0.1`. После закрытия окна, ошибки или прерывания Ghost отключает созданный ADB-транспорт и завершает свой SSH-процесс. Остальные подключения не отключаются. Проверка ключей SSH-сервера остаётся включённой.

Проверено на Redmi с Android 16: SSH-перенаправление к ADB телефона, запуск scrcpy с видео 576×1280 и завершение сеанса с очисткой подключения. Проверка проводилась без звука; звук и микрофон выбираются теми же настройками, что в пункте 29.

## Проверка и ограничения

Проверены запуск русского меню, обработка неверного пункта и выход. До перевода на Android 16 проверены чтение сведений об устройстве и создание PNG-скриншота; сведения также прочитаны с Samsung Galaxy S8 на LineageOS 23.2.

Для пункта 29 проверен запуск scrcpy 5.0.1 на Samsung Galaxy S8 с Android 16: получен видеопоток 1440×2960, сеанс корректно завершён по тестовому ограничению времени. Проверены валидация IP:порта, передача выбранного устройства в scrcpy, отсутствие scrcpy и неуспешное подключение. Ввод мышью и клавиатурой отдельно не проверялся.

Передача звука проверена на этом Samsung с AAC и тестовым флагом `--require-audio`: аудиопоток принят декодером на ПК, сеанс завершён успешно. Субъективное качество звучания не оценивалось.

Пункты 13–14 (шифрованная передача файлов) содержат унаследованную ошибку: переменная `cipher_suite` не определена. Остальные функции не прошли полную проверку. Ответы ADB и Android выводятся на исходном языке.
